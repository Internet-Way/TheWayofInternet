# Downloading

Direct download sites for software and media, plus search sites, download managers, and Usenet.

* **Note** - Always scan downloaded software with **[VirusTotal](https://www.virustotal.com/gui/)** before installation and run it in a sandboxed environment like **[Triage](https://tria.ge/)** to prevent system compromise. Many popular file hosts have download buttons that redirect to fake malicious download pages. A general rule is to avoid download pages that open in a new tab or redirected page, real downloads happen within the same page as the file host.
