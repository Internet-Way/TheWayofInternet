# Gaming

Everything gaming: trusted game downloads, emulation and ROMs, browser games, and multiplayer.

* **Note** - Many popular file hosts have download buttons that redirect to fake malicious download pages. Using the full version of [uBlock Origin](https://www.reddit.com/r/FREEMEDIAHECKYEAH/wiki/adblock-vpn-privacy#wiki_.25BA_adblocking) can prevent this but it doesn't always work. A general rule is to avoid download pages that open in a new tab or redirected page, real downloads happen within the same page as the file host.
